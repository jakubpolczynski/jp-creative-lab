# Room Drag 60 FPS Implementation Plan

**Goal:** Sustain at least 60 real rendered FPS while continuously moving each room,
with live cables, full-radius moving collisions, signals and bloom.
**Authorization:** User requested immediate autonomous execution without questions.
**Execution:** Native implementation in this session, fresh final review.
**Architecture:** Measure real pointer-driven drag before changing the solver.
Keep static collision geometry indexed; update only moving bodies, filter temporal
queries tightly, reuse transforms and eliminate unnecessary world reconstruction.
Retain directional continuous collision detection, exact A/B endpoints and unlimited feed.
**Tech:** Existing native JavaScript/WebGL2, Node and hardware Edge/Playwright.
**Spec:** Current user objective; existing flexible-cable behavior remains required.

## Alternatives / chosen direction
- Reducing visual quality, freezing other ropes or disabling collisions is rejected.
- A worker/GPU rewrite adds lifecycle/input synchronization risk before profiling.
- Optimize the existing CPU solver and moving broad phase first (agent's choice).
